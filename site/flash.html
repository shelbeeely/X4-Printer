Flash the X4 firmware

This flashes the X4 firmware binary over USB, straight from your browser, using the Web Serial API. It works in Chrome or Edge on desktop — not on mobile, not in Firefox or Safari. Plug the X4 into your computer via USB before starting. Web Serial also requires HTTPS, which GitHub Pages already provides.

Flashing firmware alone does not provision the SD card (Wi-Fi credentials, device pairing). See Setup for the rest of the device setup.

Before you start

  • USB cable connected between the X4 and your computer.
  • Chrome or Edge, on desktop (not mobile).
  • Nothing else has the device's serial port open (close any serial monitor or terminal connected to it).
Your browser doesn't support Web Serial. Use Chrome or Edge on desktop. Web Serial needs HTTPS. If you're seeing this on the live site, please open an issue.

Firmware isn't published yet

Build and flash it yourself:

cd firmware
git clone https://github.com/Free-Ink/freeink-sdk
pio run -e xteink_x4 -t upload

See docs/setup-x4.md for the full walkthrough, including SD card provisioning.
