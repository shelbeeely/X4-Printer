Setup

Two things to set up: the Pi print server, and the X4 device itself.

1. Set up the Pi

Target: a Raspberry Pi (Zero W or better) running Raspberry Pi OS Bookworm or newer, on the same LAN as the X4, with a physical network/USB printer already reachable from it. 

git clone <this-repo>
cd X4-Printer/pi-server
sudo ./install/install.sh

This installs CUPS, avahi-daemon, creates a xteink-print system user, sets up a Python virtualenv, generates a self-signed TLS certificate for the sync API, and starts the xteink-print-server systemd service. After that you point it at your CUPS queue (XTEINK_CUPS_QUEUE) and pair your first X4 with pair_device.py, which produces the device.json and CA cert files the X4 needs.

Full walkthrough (CUPS printer config, mDNS troubleshooting, pairing, end-to-end verification without hardware): docs/setup-pi.md

2. Set up the X4

cd firmware
git clone https://github.com/Free-Ink/freeink-sdk
pio run -e xteink_x4
pio run -e xteink_x4 -t upload

Or flash from your browser — no toolchain needed

Then provision a FAT32 microSD card with these files at its root: 

/system/device.json      <- from pi-server/tools/pair_device.py
/system/pi_ca.pem        <- pi-server's tls/server.crt
/system/wifi.json        <- hand-written, see docs/setup-x4.md

On first boot the firmware connects to the strongest saved Wi-Fi network, runs one sync pass (nothing to download yet on a fresh device), and opens the Print Inbox UI. If device.json is missing or Wi-Fi isn't configured, the sync pass is a no-op and the Inbox screen just shows "Inbox empty" until you've paired the device and printed something.

Full walkthrough (SD card provisioning details, using the Print Inbox, remote approval, troubleshooting): docs/setup-x4.md
